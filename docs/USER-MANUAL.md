## 1. บทนำและภาพรวมระบบ

ระบบบริหารจัดการสมาชิกองค์การนักวิชาชีพในอนาคตแห่งประเทศไทย วิทยาลัยเทคนิคมีนบุรี เป็นระบบเว็บแอปพลิเคชันสำหรับเจ้าหน้าที่และคณะกรรมการดำเนินงาน ใช้ในการ:
- จัดเก็บและบริหารฐานข้อมูลสมาชิกองค์การนักวิชาชีพในอนาคตแห่งประเทศไทย (อวท.) วิทยาลัยเทคนิคมีนบุรี อย่างเป็นระบบและปลอดภัย
- บันทึกประวัติการดำรงตำแหน่งรายปีการศึกษา ไทม์ไลน์การศึกษา ผลงาน และกิจกรรม
- รองรับงานทะเบียนและพิมพ์แบบฟอร์มเอกสารทางการของ อวท. ได้แก่ **อวท.10 (ใบสมัคร)**, **อวท.09 (ประกาศแต่งตั้งคณะกรรมการ)** และ **อวท.08 (รายงานการเลือกตั้ง)**
- สรุปสถิติภาพรวม แผนภูมิ และส่งออกรายงานเป็นไฟล์ **Excel (.xlsx)** และ **PDF ภาษาไทย (ฟอนต์ Sarabun)**
- กำหนดสิทธิ์การเข้าใช้งานของเจ้าหน้าที่อย่างรัดกุม ไม่มีหน้าเว็บสาธารณะ ข้อมูลและรูปถ่ายทั้งหมดได้รับการปกป้องด้วยระบบตรวจสอบสิทธิ์ (JWT Token)

## 2. การเริ่มต้นใช้งานระบบ (Getting Started)

### 2.1 การเปิดระบบ

#### บนระบบปฏิบัติการ Windows:
1. ไปที่โฟลเดอร์โปรเจกต์ `managemember`
2. ดับเบิลคลิกไฟล์ **`run.bat`**
   - สคริปต์จะตรวจสอบความพร้อมของ Python, ติดตั้งแพ็กเกจที่จำเป็นอัตโนมัติ (ครั้งแรก) และเปิดเซิร์ฟเวอร์
3. เปิดเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge หรือ Firefox) แล้วเข้าไปที่:
   ```
   http://127.0.0.1:5000
   ```

#### ผ่าน Terminal / Command Line:
```bash
cd backend
python app.py
```
เปิดเบราว์เซอร์ที่ `http://127.0.0.1:5000`

---

### 2.2 การเข้าสู่ระบบครั้งแรก

เมื่อเปิดระบบ จะพบหน้าจอเข้าสู่ระบบ:

| ข้อมูลที่ต้องกรอก | ค่าเริ่มต้นสำหรับใช้งานครั้งแรก |
|---|---|
| **ชื่อผู้ใช้ (Username)** | `admin` |
| **รหัสผ่าน (Password)** | `admin1234` |

คลิกปุ่ม **"เข้าสู่ระบบ"** เพื่อเข้าใช้งานระบบ

> [!IMPORTANT]
> **เพื่อความปลอดภัย:** บัญชี `admin` เป็นบัญชีผู้ดูแลระบบสูงสุด (Superadmin) แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังการใช้งานครั้งแรก

---

### 2.3 การเปลี่ยนรหัสผ่านเพื่อความปลอดภัย

1. คลิกที่รูปโปรไฟล์หรือชื่อของคุณที่ **มุมขวาบนของหน้าจอ**
2. เลือกเมนู **"เปลี่ยนรหัสผ่าน"**
3. กรอกข้อมูล:
   - รหัสผ่านเดิม
   - รหัสผ่านใหม่ (ต้องมีความยาวอย่างน้อย 8 ตัวอักษร)
   - ยืนยันรหัสผ่านใหม่อีกครั้ง
4. คลิกปุ่ม **"เปลี่ยนรหัสผ่าน"**

### 2.4 ส่วนประกอบหน้าจอหลัก

หน้าจอของระบบประกอบด้วย 3 ส่วนสำคัญ:

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│      │ Header: ชื่อหน้าปัจจุบัน | ช่องค้นหาด่วน | วันที่ | ข้อมูลผู้ใช้  │
│ Side ├──────────────────────────────────────────────────────────────────┤
│ bar  │ Content Area:                                                    │
│      │ แสดงเนื้อหาของแต่ละเมนู (แดชบอร์ด, ตารางสมาชิก, ฟอร์ม, รายงาน)      │
│ (Icon│                                                                  │
│ Menu)│                                                                  │
└──────┴──────────────────────────────────────────────────────────────────┘
```

- **Sidebar ด้านซ้าย:** แถบนำทางด่วน พร้อมไอคอนและ Tooltip เมื่อนำเมาส์ไปชี้:
  - 📊 **Dashboard:** ภาพรวมสถิติและแผนภูมิ
  - 👥 **สมาชิก:** ตารางรายชื่อ ค้นหา และกรอง
  - ➕ **รับสมาชิก:** ฟอร์มลงทะเบียนสมาชิกใหม่
  - 🔍 **สืบค้น:** ค้นหาประวัติสมาชิกแบบละเอียด
  - 🏅 **ตำแหน่ง:** กำหนดตำแหน่งและแผนกวิชา
  - 💼 **คณะกรรมการ (อวท.09):** จัดการคณะกรรมการและพิมพ์ประกาศ อวท.09
  - ☑️ **การเลือกตั้ง (อวท.08):** บันทึกผลการเลือกตั้งและพิมพ์รายงาน อวท.08
  - 📅 **ปีการศึกษา:** จัดการปี พ.ศ. และกำหนดปีปัจจุบัน
  - 📑 **รายงาน:** ส่งออกข้อมูล Excel / PDF
  - 🛡️ **ผู้ใช้งาน:** จัดการบัญชีผู้ใช้และสำรองฐานข้อมูล
  - 🚪 **ออกจากระบบ:** ปุ่มออกจากระบบที่มุมล่าง
- **Header ด้านบน:**
  - แสดงชื่อหน้าและคำอธิบายย่อย
  - **ช่องค้นหาสมาชิกด่วน (Quick Search):** พิมพ์ชื่อ-นามสกุล หรือเลขสมาชิก แล้วกด Enter จะไปยังหน้ารายละเอียดทันที
  - **โปรไฟล์ผู้ใช้:** แสดงชื่อ บทบาท และเมนูเปลี่ยนรหัสผ่าน / ออกจากระบบ

## 3. หน้าแดชบอร์ดภาพรวม (Dashboard)

แดชบอร์ดช่วยให้ผู้บริหารและเจ้าหน้าที่เห็นภาพรวมขององค์การได้ทันที:

1. **ตัวเลือกปีการศึกษา (ขวาบน):**
   - สามารถคลิกเปลี่ยนปีการศึกษา เพื่อดูสถิติย้อนหลังของปีที่ต้องการ หรือดูปีการศึกษาปัจจุบัน
2. **การ์ดสรุปตัวเลขหลัก (Stat Cards):**
   - **สมาชิกทั้งหมด:** จำนวนสมาชิกสะสมทั้งหมดในฐานข้อมูล
   - **สมาชิกปีการศึกษาปัจจุบัน:** จำนวนสมาชิกที่สังกัดหรือดำรงตำแหน่งในปีที่เลือก
   - **จำนวนกรรมการ:** จำนวนคณะกรรมการดำเนินงานในปีนั้น
3. **แผนภูมิวิเคราะห์ (Charts):**
   - สัดส่วนสมาชิกแยกตามตำแหน่ง (ประธาน, รองประธาน, กรรมการ, สมาชิกทั่วไป)
   - จำนวนสมาชิกแยกตามแผนกวิชา
   - สถานะของสมาชิก (ปกติ, รอตรวจสอบ, พ้นสภาพ)
4. **การ์ดแจ้งเตือนข้อมูลไม่สมบูรณ์ (Incomplete Warning):**
   - ระบบจะช่วยตรวจเช็คและแสดงรายชื่อสมาชิกที่ยังไม่ได้อัปโหลดรูปถ่าย หรือยังไม่ได้ระบุตำแหน่ง เพื่อให้เจ้าหน้าที่เข้าไปปรับปรุงข้อมูลให้ครบถ้วน

## 4. การรับสมัครและบันทึกข้อมูลสมาชิก (Member Registration)

เข้าใช้งานผ่านเมนู **"รับสมาชิก"** หรือปุ่ม **"+ เพิ่มสมาชิก"**

### 4.1 ข้อมูลส่วนตัวและการศึกษา
- **เลขประจำตัวสมาชิก (10 หลัก):**
  - รูปแบบ: `ปี พ.ศ. 4 หลัก` + `ลำดับ 6 หลัก` เช่น `2569000001`
  - มีปุ่ม **"ขอเลขถัดไป"** ระบบจะคำนวณและเติมเลขอัตโนมัติตามปี พ.ศ. ล่าสุด
  - ระบบตรวจสอบความซ้ำแบบ Real-time ทันทีที่พิมพ์ หากเลขซ้ำจะมีแจ้งเตือนทันที
- **คำนำหน้า, ชื่อ, นามสกุล:** กรอกภาษาไทยให้ถูกต้อง
- **ชื่อ-นามสกุลภาษาอังกฤษ:** สำหรับใช้แสดงผลในการ์ดภาษาอังกฤษ
- **แผนกวิชา และระดับชั้น:** เช่น ปวช.1, ปวช.2, ปวส.1
- **สถานะ:** 
  - `ปกติ (Active)`: สมาชิกปัจจุบัน
  - `รอตรวจสอบ (Pending)`: บันทึกข้อมูลเบื้องต้น รอเอกสาร
  - `พ้นสภาพ (Inactive)`: สำเร็จการศึกษา หรือลาออก

### 4.2 ข้อมูลที่อยู่ตามทะเบียนบ้าน
ระบบมีฐานข้อมูลที่อยู่ประเทศไทยครบถ้วนทุกจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์:
- กรอก บ้านเลขที่, หมู่, ซอย, ถนน
- **เลือกจังหวัด → อำเภอ/เขต → ตำบล/แขวง:**
  - ระบบจะกรองตัวเลือกอำเภอตามจังหวัดที่เลือกโดยอัตโนมัติ
  - เมื่อเลือกตำบล **รหัสไปรษณีย์จะถูกเติมให้ทันทีโดยอัตโนมัติ**

### 4.3 ทะเบียนสมาชิกตามแบบ อวท.10
- **ทะเบียนเลขที่:** เลขทะเบียนตามสมุดทะเบียน อวท.
- **ระดับสมาชิก:** เช่น `สามัญ ระดับสถานศึกษา`
- **นายทะเบียน:** ชื่อเจ้าหน้าที่นายทะเบียนผู้รับสมัคร
- **วันที่ลงทะเบียน:** วันที่บันทึกข้อมูลรับสมาชิก

### 4.4 การกำหนดตำแหน่งประจำปี
- สมาชิก 1 คนสามารถมีประวัติตำแหน่งได้หลายปีการศึกษา (ปีละ 1 ตำแหน่ง)
- หากไม่ระบุ ระบบจะตั้งเป็น **"สมาชิกทั่วไป"** ให้อัตโนมัติ
- สามารถเพิ่มประวัติการศึกษาเดิม และผลงาน/กิจกรรม/รางวัล พร้อมระบุปีที่ได้รับ

### 4.5 การอัปโหลดรูปถ่ายและคลังภาพ
- **รูปถ่ายประจำตัว (Profile Photo):** รองรับไฟล์ JPG, PNG, WebP ขนาดไม่เกิน 5 MB
  - มีระบบตัดรูปสี่เหลี่ยมจัตุรัสและพรีวิวตัวอย่างก่อนบันทึก
- **คลังรูปภาพกิจกรรม (Gallery):** อัปโหลดภาพกิจกรรม เกียรติบัตร หรือผลงานเพิ่มเติมได้ไม่จำกัด

## 5. การจัดการและสืบค้นข้อมูลสมาชิก (Members & Search)

### 5.1 การกรองและค้นหารายชื่อ (หน้า "สมาชิก")
- **ช่องค้นหา:** ค้นหาได้ทั้ง ชื่อ, นามสกุล, ชื่อเล่น หรือเลขสมาชิก
- **ตัวกรองด้านบน:**
  - กรองตามปีการศึกษา
  - กรองตามแผนกวิชา
  - กรองตามตำแหน่ง
  - กรองตามสถานะสมาชิก
- **การเรียงลำดับ (Sorting):** สามารถคลิกหัวตารางเพื่อเรียงตาม ลำดับ, เลขสมาชิก, ชื่อ-นามสกุล หรือตำแหน่ง

### 5.2 การแก้ไขและลบข้อมูล
- คลิกที่ไอคอน **แก้ไข (ดินสอ)** เพื่อเปิดหน้าฟอร์มแก้ไขข้อมูล
- คลิกที่ไอคอน **ดูประวัติ (ดวงตา)** หรือคลิกที่ชื่อสมาชิก เพื่อเปิดหน้าดูประวัติแบบละเอียด
- คลิกที่ไอคอน **ลบ (ถังขยะ)** เพื่อลบสมาชิก:
  - ระบบจะมีกล่องข้อความยืนยันความปลอดภัยเพื่อป้องกันการลบโดยไม่ตั้งใจ
  - เมื่อลบสมาชิก ข้อมูลประวัติและไฟล์รูปภาพในโฟลเดอร์จะถูกล้างอย่างสมบูรณ์

### 5.3 การจัดการสถานะสมาชิกเป็นกลุ่ม (Bulk Actions)
- สามารถคลิกเครื่องหมายถูก `☑` หน้ารายชื่อสมาชิกหลายๆ คนพร้อมกัน
- แถบเมนูด้านล่างจะปรากฏขึ้น ให้เลือก:
  - **เปลี่ยนสถานะเป็นกลุ่ม:** เช่น เปลี่ยนเป็น "ปกติ" หรือ "พ้นสภาพ" พร้อมกันในคลิกเดียว
  - **ลบรายการที่เลือก:** ลบสมาชิกที่เลือกทั้งหมดพร้อมกัน

## 6. รูปแบบการแสดงประวัติสมาชิก (Profile Templates)

ระบบเตรียมแม่แบบการแสดงผลข้อมูลสมาชิกไว้ 4 รูปแบบ เพื่อตอบโจทย์การใช้งานที่แตกต่างกัน:

### 6.1 Profile Card (การ์ดสรุปย่อ)
- รูปแบบกระชับ เน้นรูปถ่าย ชื่อ ตำแหน่ง เลขสมาชิก แผนกวิชา และช่องทางติดต่อ (โทรศัพท์, Email, LINE)
- เหมาะสำหรับ: การตรวจเช็คข้อมูลทั่วไป หรือแคปเจอร์เป็นการ์ดแนะนำตัว

### 6.2 Biography (ประวัติส่วนตัวฉบับสมบูรณ์)
- แสดงประวัติละเอียด: ข้อมูลบุคคล ไทม์ไลน์การศึกษา ข้อมูลบิดา-มารดา ที่อยู่ตามทะเบียนบ้าน และข้อมูลทะเบียน อวท.10
- เหมาะสำหรับ: เจ้าหน้าที่งานทะเบียนและอาจารย์ที่ปรึกษาใช้ตรวจดูประวัติอย่างละเอียด

### 6.3 Executive Profile (สำหรับผู้บริหารและผู้นำ)
- ออกแบบเป็นพิเศษสำหรับ ประธาน และรองประธาน
- โดดเด่นด้วย แบนเนอร์หัวเรื่อง, วิสัยทัศน์/คติประจำใจ, ตราตำแหน่งผู้บริหาร และสรุปประวัติการดำรงตำแหน่ง
- เหมาะสำหรับ: แนะนำคณะผู้บริหารองค์การต่อนักศึกษาและบุคคลภายนอก

### 6.4 Portfolio (แฟ้มสะสมผลงาน)
- แสดงเกียรติประวัติ ผลงาน รางวัลที่ได้รับ พร้อมแกลเลอรีรูปภาพกิจกรรม
- เหมาะสำหรับ: สมาชิกที่มีผลงานแข่งขัน ทักษะวิชาชีพ หรือกิจกรรมโดดเด่น

> [!TIP]
> เจ้าหน้าที่สามารถคลิกปุ่ม **"ตั้งเป็นรูปแบบหลัก"** ในหน้าประวัติสมาชิก เพื่อกำหนดให้สมาชิกคนนั้นเปิดด้วยแม่แบบที่ต้องการเสมอได้

## 7. งานเอกสารแบบฟอร์มทางการ อวท. (Official Forms)

ระบบรองรับการออกเอกสารทางการตามระเบียบขององค์การนักวิชาชีพในอนาคตแห่งประเทศไทย โดยจัดหน้าตามแบบฟอร์มมาตรฐานของส่วนกลาง:

### 7.1 แบบ อวท.10 — ใบสมัครสมาชิก
- **วิธีเปิดใช้งาน:** เข้าหน้าดูประวัติสมาชิกคนใดก็ได้ → คลิกปุ่ม **"ใบสมัคร อวท.10"**
- ระบบจะนำข้อมูลส่วนตัว ที่อยู่ การศึกษา และผู้ปกครอง มาจัดวางลงในแบบฟอร์มใบสมัคร อวท.10 ครบทุกช่อง
- สามารถคลิก **"พิมพ์ / บันทึกเป็น PDF"** เพื่อสั่งพิมพ์ลงกระดาษ A4 ได้ทันที

### 7.2 แบบ อวท.09 — ประกาศแต่งตั้งคณะกรรมการดำเนินงาน
- **วิธีเปิดใช้งาน:** เข้าเมนู **"คณะกรรมการ (อวท.09)"**
- เลือกปีการศึกษาที่ต้องการ
- ระบบจะดึงรายชื่อคณะกรรมการดำเนินงานตามลำดับมาตรฐานของ อวท.:
  1. ประธาน
  2. รองประธาน
  3. กรรมการ
  4. เหรัญญิก
  5. ปฏิคม
  6. นายทะเบียน
  7. ประชาสัมพันธ์
  8. เลขานุการ
- สามารถกรอก **ชื่อผู้อำนวยการวิทยาลัย** ในช่องผู้ลงนาม
- คลิกปุ่ม **"ประกาศ อวท.09 (PDF)"** เพื่อรับไฟล์ประกาศพร้อมตราสัญลักษณ์ และช่องลงนามของประธานกรรมการบริหารและผู้อำนวยการ

### 7.3 แบบ อวท.08 — รายงานผลการเลือกตั้ง
- **วิธีเปิดใช้งาน:** เข้าเมนู **"การเลือกตั้ง (อวท.08)"**
- บันทึกการเลือกตั้งประจำปีการศึกษา:
  - วันที่จัดเลือกตั้ง
  - ตำแหน่งที่จัดการเลือกตั้ง (เช่น นายกองค์การ / ประธาน)
  - รายชื่อผู้สมัคร และคะแนนเสียงที่ได้รับ
  - กำหนดผู้ชนะการเลือกตั้ง
- ระบุรายชื่อผู้ลงนาม 5 ฝ่ายตามแบบ อวท.:
  1. ผู้รายงานผล
  2. ครูที่ปรึกษาคณะกรรมการ
  3. หัวหน้างานกิจกรรมนักเรียนนักศึกษา
  4. รองผู้อำนวยการฝ่ายพัฒนากิจการนักเรียนนักศึกษา
  5. ผู้อำนวยการวิทยาลัยเทคนิคมีนบุรี
- คลิกปุ่ม **"รายงาน อวท.08 (PDF)"** เพื่อพิมพ์เอกสารทางการ

## 8. ระบบรายงานและการส่งออกข้อมูล (Reports & Export)

เข้าใช้งานผ่านเมนู **"รายงาน"**

### 8.1 การออกรายงานรายชื่อ
1. กำหนดเงื่อนไขที่ต้องการกรอง:
   - ปีการศึกษา (หรือเลือก "ทุกปีการศึกษา")
   - ตำแหน่ง (หรือเลือก "ทุกตำแหน่ง")
   - แผนกวิชา
   - สถานะสมาชิก
2. ตารางตัวอย่างด้านล่างจะแสดงรายชื่อ ลำดับ เลขสมาชิก ชื่อ ตำแหน่ง แผนก และเบอร์ติดต่อทันที

### 8.2 ตารางสรุป Matrix ตำแหน่ง × แผนกวิชา
- แสดงตารางวิเคราะห์เชิงสถิติ:
  - แถว = แผนกวิชาต่างๆ ภายในวิทยาลัย
  - คอลัมน์ = แต่ละตำแหน่ง (ประธาน, รองประธาน, กรรมการ, สมาชิก ฯลฯ)
  - ช่องสุดท้าย = ผลรวมแต่ละแผนก และแถวล่างสุด = ผลรวมทั้งหมด

### 8.3 การส่งออกเป็น Excel และ PDF
- **ปุ่ม "ส่งออก Excel (.xlsx)":**
  - ชีตที่ 1: รายชื่อสมาชิกตามเงื่อนไข พร้อมจัดความกว้างคอลัมน์และสีหัวตารางสวยงาม
  - ชีตที่ 2: ตารางสรุปจำนวนสมาชิกตามตำแหน่งและแผนกวิชา
- **ปุ่ม "ส่งออก PDF":**
  - เอกสารจัดพิมพ์แนวนอน (Landscape) ฟอนต์ Sarabun คมชัด
  - มีหัวรายงานทางการ ระบุวันที่พิมพ์ และผู้สั่งพิมพ์
  - มีแถบกำกับหมายเลขหน้าและท้ายเอกสาร "เอกสารภายใน — ระบบบริหารจัดการสมาชิก..."

## 9. การจัดการข้อมูลพื้นฐาน (Settings)

> *ต้องมีสิทธิ์ `settings` หรือเป็น Superadmin/Admin*

### 9.1 จัดการปีการศึกษา (เมนู "ปีการศึกษา")
- **การเพิ่มปีการศึกษา:** กรอกเลขปี พ.ศ. เช่น `2569` ระบบจะคำนวณวันเริ่มต้น (16 พ.ค.) และวันสิ้นสุด (31 มี.ค.) ให้โดยอัตโนมัติ
- **การตั้งปีการศึกษาปัจจุบัน:** คลิกปุ่ม **"ตั้งเป็นปีปัจจุบัน"** ที่ปีที่ต้องการ เพื่อให้ระบบใช้ปีนี้เป็นค่าเริ่มต้นในทุกฟอร์มและแดชบอร์ด

### 9.2 จัดการตำแหน่ง (เมนู "ตำแหน่ง")
- กำหนดชื่อตำแหน่ง เช่น ประธาน, รองประธาน, กรรมการ, เหรัญญิก, เลขานุการ, สมาชิกทั่วไป
- กำหนดลำดับความสำคัญ (Level) เพื่อใช้ในการจัดเรียงในรายงาน
- กำหนดประเภท:
  - เป็นตำแหน่งผู้บริหารหรือไม่ (Executive)
  - เป็นตำแหน่งในคณะกรรมการหรือไม่ (Committee)
- เลือกสีป้ายกำกับตำแหน่ง (Badge Color)

### 9.3 จัดการแผนกวิชา
- เพิ่ม ลบ หรือแก้ไขชื่อแผนกวิชาภายในวิทยาลัย (เช่น แผนกวิชาช่างยนต์, แผนกวิชาคอมพิวเตอร์ธุรกิจ, แผนกวิชาไฟฟ้ากำลัง ฯลฯ)

### 9.4 ตั้งค่าข้อมูลการสมัคร (เมนู "ตั้งค่าข้อมูลการสมัคร")
- **ตัวเลือกในแบบฟอร์มสมัคร:** เพิ่ม แก้ไข ลบ และจัดลำดับรายการในช่องดรอปดาวน์ของหน้ารับสมาชิก ได้แก่ คำนำหน้า, เพศ, กรุ๊ปเลือด, ระดับชั้น และระดับสมาชิก
  - แก้ไขชื่อตัวเลือก → ข้อมูลสมาชิกที่ใช้ตัวเลือกนั้นจะเปลี่ยนตามชื่อใหม่
  - ลบตัวเลือก → ข้อมูลของสมาชิกที่เลือกไว้แล้วไม่เปลี่ยน แต่จะเลือกกับสมาชิกรายอื่นไม่ได้อีก
- **ข้อมูลที่อยู่:** แสดงจังหวัดทั้งหมด คลิกจังหวัดเพื่อดูอำเภอ/เขต และคลิกอำเภอเพื่อดูตำบล/แขวงพร้อมรหัสไปรษณีย์
  - กด **"เพิ่ม"** เพื่อเพิ่มจังหวัด อำเภอ หรือตำบลใหม่ (ตำบลต้องกรอกรหัสไปรษณีย์ 5 หลักเอง)
  - กด **⋮** ท้ายรายการเพื่อแก้ไขชื่อ/รหัสไปรษณีย์ หรือลบ (ลบไม่ได้ถ้ามีสมาชิกใช้ที่อยู่นั้นอยู่)
- ในหน้ารับสมาชิก ยังเลือก **"+ เพิ่ม...ใหม่"** ท้ายดรอปดาวน์จังหวัด/อำเภอ/ตำบล และพิมพ์รหัสไปรษณีย์เองได้เช่นเดิม

## 10. การจัดการผู้ใช้งาน สิทธิ์ และการสำรองข้อมูล (Users & Backup)

เข้าใช้งานผ่านเมนู **"ผู้ใช้งาน"**

### 10.1 บทบาทและสิทธิ์การใช้งาน
ระบบแบ่งบทบาทหลักเป็น 3 ระดับ พร้อมการกำหนดสิทธิ์ย่อย 7 รายการ:

| สิทธิ์ | superadmin | admin | staff | คำอธิบาย |
|---|:---:|:---:|:---:|---|
| `members.view` | ✓ | ✓ | ✓ | ดูรายชื่อ ค้นหา และดูประวัติสมาชิก |
| `members.edit` | ✓ | ✓ | | เพิ่มและแก้ไขข้อมูลสมาชิก |
| `members.delete` | ✓ | ✓ | | ลบข้อมูลสมาชิก |
| `settings` | ✓ | ✓ | | เพิ่ม/แก้ ตำแหน่ง, แผนกวิชา, ปีการศึกษา |
| `reports` | ✓ | ✓ | ✓ | ดูและส่งออกรายงาน Excel/PDF |
| `backup` | ✓ | ✓ | | สำรองฐานข้อมูล และดาวน์โหลดไฟล์สำรอง |
| `users` | ✓ | | | เพิ่ม แก้ไข กำหนดสิทธิ์ และรีเซ็ตรหัสผู้ใช้ |

> [!TIP]
> ผู้ดูแลระบบสามารถปรับแต่งสิทธิ์รายบุคคลได้ เช่น ให้เจ้าหน้าที่ระดับ Staff บางคนสามารถออกรายงานได้ หรือแก้ไขข้อมูลได้เฉพาะบางงาน

### 10.2 การเพิ่มและจัดการผู้ใช้งาน
1. คลิกปุ่ม **"+ เพิ่มผู้ใช้"**
2. กรอก ชื่อผู้ใช้ (Username), ชื่อ-นามสกุล, เลือกรหัสผ่านเริ่มต้น และเลือกบทบาท
3. สามารถเลือกติ๊กเปิด/ปิดสิทธิ์เฉพาะทางได้ตามต้องการ
4. หากต้องการระงับการใช้งานชั่วคราว สามารถปิดสวิตช์ **"เปิดใช้งาน"** โดยไม่ต้องลบบัญชี

### 10.3 การสำรองและกู้คืนฐานข้อมูล (Database Backup)
- **การสำรองข้อมูลทันที:**
  - คลิกปุ่ม **"สำรองข้อมูลตอนนี้"**
  - ระบบจะสร้างไฟล์ Snapshot ของฐานข้อมูลปัจจุบัน เก็บไว้ในโฟลเดอร์ `database/backups/` ในชื่อรูปแบบ `app_YYYYMMDD_HHMMSS.db`
- **การดาวน์โหลดไฟล์สำรอง:**
  - คลิกที่ไอคอนดาวน์โหลด เพื่อบันทึกไฟล์ `.db` เก็บสำรองไว้ใน Flash Drive หรือเครื่องคอมพิวเตอร์ภายนอก
- **การกู้คืนข้อมูล (Restore):**
  - ปิดเซิร์ฟเวอร์
  - นำไฟล์สำรองที่ต้องการมาเปลี่ยนชื่อเป็น `app.db` แล้วนำไปวางแทนที่ในโฟลเดอร์ `database/app.db`
  - เปิดเซิร์ฟเวอร์ขึ้นมาใหม่

## 11. การเปิดใช้งานในเครือข่ายภายในวิทยาลัย (LAN / Wi-Fi)

หากต้องการให้คอมพิวเตอร์เครื่องอื่นภายในแผนกวิชา หรือเครือข่ายของวิทยาลัยสามารถเข้าใช้งานระบบได้พร้อมกัน:

1. เปิดไฟล์ **`.env`** ในโฟลเดอร์หลักของโปรเจกต์
2. ค้นหาบรรทัด `HOST` และเปลี่ยนจาก `127.0.0.1` เป็น:
   ```env
   HOST=0.0.0.0
   PORT=5000
   ```
3. บันทึกไฟล์ และรีสตาร์ตเซิร์ฟเวอร์ (`run.bat`)
4. ตรวจสอบหมายเลข IP Address ของเครื่องแม่ข่าย (เช่น `192.168.1.100`)
5. เครื่องคอมพิวเตอร์เครื่องอื่นที่เชื่อมต่อเครือข่ายเดียวกัน สามารถเข้าใช้งานผ่านเบราว์เซอร์ได้ที่:
   ```
   http://192.168.1.100:5000
   ```

## 12. คำถามที่พบบ่อยและการแก้ไขปัญหา (FAQ & Troubleshooting)

### Q1: ลืมรหัสผ่านของบัญชี Admin ต้องทำอย่างไร?
**ตอบ:** สามารถรีเซ็ตรหัสผ่านของบัญชี admin ได้โดยรันคำสั่งผ่าน Command Line ในโฟลเดอร์ `backend`:
```bash
python -c "from app import create_app; from models import db, User; app = create_app(); app.app_context().push(); u = User.query.filter_by(username='admin').first(); u.set_password('admin1234'); db.session.commit(); print('Reset password complete!')"
```
รหัสผ่านจะกลับไปเป็น `admin1234`

### Q2: ฟอนต์ภาษาไทยในไฟล์ PDF แสดงผลผิดเพี้ยนหรือไม่เป็นตัวหนังสือ?
**ตอบ:** ระบบมาพร้อมกับฟอนต์ **Sarabun** ในโฟลเดอร์ `backend/fonts/` หากฟอนต์หายไป ระบบจะพยายามดึงฟอนต์ภาษาไทยของ Windows (เช่น Leelawadee UI หรือ Tahoma) มาใช้งานแทน สามารถตรวจสอบให้แน่ใจว่าโฟลเดอร์ `backend/fonts/` มีไฟล์ฟอนต์ครบถ้วน

### Q3: หน้าเว็บแจ้งเตือน "เซสชันหมดอายุ กรุณาเข้าสู่ระบบใหม่"?
**ตอบ:** ระบบถูกตั้งค่าความปลอดภัยให้ Token มีอายุ 8 ชั่วโมง หากไม่ได้ใช้งานเป็นเวลานานจนเซสชันหมด ให้ล็อกอินใหม่อีกครั้งเพื่อความปลอดภัยของข้อมูล

### Q4: ไม่สามารถลบตำแหน่ง หรือแผนกวิชาได้ มีข้อความแจ้งเตือน?
**ตอบ:** เพื่อรักษาความถูกต้องของประวัติ ระบบจะไม่อนุญาตให้ลบตำแหน่งหรือแผนกวิชาที่มีสมาชิกผูกข้อมูลอยู่ หากต้องการลบ ต้องย้ายสมาชิกในตำแหน่งหรือแผนกนั้นไปยังตำแหน่ง/แผนกอื่นก่อน
